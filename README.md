## 📌 Deskripsi Proyek
Sebuah platform E-Commerce berbasis web yang dirancang khusus untuk penjualan produk kecantikan dan perawatan kulit "Sri Glow Skincare". Proyek ini dikembangkan pada Semester 5 sebagai pemenuhan tugas besar mata kuliah Pemrograman Web / Rekayasa Perangkat Lunak di Universitas Almuslim.

Sistem ini mempermudah pelanggan dalam menjelajahi katalog produk, melakukan pemesanan, hingga mengelola keranjang belanja secara online dan responsif.

## 🎯 Fitur Utama
- **Katalog Produk**: Tampilan produk kecantikan interaktif berdasarkan kategori (Skincare, Bodycare, dll).
- **Manajemen Keranjang (Cart)**: Fitur tambah, kurang, dan hapus item belanjaan sebelum checkout.
- **Sistem Checkout**: Formulir pemesanan ringkas beserta kalkulasi total harga belanjaan.
- **Autentikasi Pengguna**: Fitur registrasi dan login untuk pelanggan.
- **Halaman Admin**: Panel khusus untuk mengelola data stok produk, kategori, dan melihat pesanan masuk.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap (Responsive Design)
- **Backend**: PHP (atau sebutkan framework jika pakai CodeIgniter/Laravel)
- **Database**: MySQL
